# Python Function Assignment

This repository contains a simple Python program demonstrating the use of `def` functions.

## Program Description

The program asks the user to enter a string and then passes the string through a series of functions.

* Functions 1-5 progressively double the input string.
* Functions 6-10 calculate counts based on the string and previously calculated counts.
* The final function displays the resulting string and counts.

## Purpose of `def`

A `def` function is used to define a reusable block of code that can be called whenever that functionality is needed.

## Files

* `main.py` - Contains the Python program demonstrating function definitions and function calls.
